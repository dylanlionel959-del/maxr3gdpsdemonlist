# App Preview & Website Showcase

An interactive web project designed to display app and website previews with a modern and engaging interface.

![App Preview](assets/images/app-preview.jpg)

---

## 🚀 Features

- **Responsive Design:** Adaptable across mobile devices, tablets, and desktop screens.
- **High-Quality Previews:** Interactive screenshot gallery showcasing the app and website layout.
- **CI/CD Integration:** Automated GitHub Actions workflows for continuous merging and testing.
